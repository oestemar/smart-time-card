# Smart Time Card
## 1.システム概要
出退勤の打刻管理と集計のためのアプリケーションです。下記のような機能があります。
- 開始or終了の選択、出社or在宅の選択をする
- 毎月の休憩時間の設定
- 月ごとの勤務時間集計
- CSVでの出力とメールで自分へ送信
- 期間指定の集計

## 2.必須機能
- 出勤・退勤打刻
- 出社・在宅登録
- 打刻履歴表示
- 休憩時間の設定
- 月別勤務時間集計
- 期間指定集計
- CSV出力

## 3.将来的機能
- 通知機能
- メール送信
